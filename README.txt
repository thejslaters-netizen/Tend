TEND — PEACEFUL HOMEKEEPING

How to open:
1. Open index.html in a browser on a computer.
2. For the best phone experience, place the folder on a simple web host or run a local web server.

Simple local server on a computer with Python installed:
- Open a terminal in this folder.
- Run: python -m http.server 8000
- Open: http://localhost:8000

The app saves progress on the device using browser storage.
